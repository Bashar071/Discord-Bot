​Multipurpose Discord Bot:
​This repository contains the source code for a feature-rich Discord bot developed using Node.js. The bot is designed to be an all-in-one solution for server management, providing tools for moderation, user engagement, and support.


​✨ Features
​Based on the project files, the bot includes the following functionalities:


​🛡️ Moderation Suite
​Ban/Unban: Ban and unban members from the server.
​Kick: Kick members from the server.
​Mute/Unmute: Mute and unmute members in text or voice channels.
​Warn/Unwarn: Issue warnings to members and remove them.
​Role Management: Commands to manage user roles.
​Nickname: Manage and change user nicknames.


​🛠️ Utility & Information
​Help Command: A comprehensive list of all available commands.
​Server Info: Get detailed statistics and information about the server.
​User Info: Display information about a specific user (e.g., join date, roles).


​🎫 Support System
​Ticket System: A complete ticket system allowing users to create private support channels with staff for assistance.


​🎉 Entertainment & Fun
​Songs: Music functionality to play songs in voice channels.
​Tic-Tac-Toe: A fun titato.js command to play Tic-Tac-Toe with other members.


​💻 Tech Stack
​Language: JavaScript
​Runtime: Node.js
​Library: discord.js
